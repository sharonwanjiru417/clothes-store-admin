# 👗 Threads & Co - Admin Portal

An e-commerce admin portal built with React and Vite.

## Features
- 🏠 Landing page with store info
- 🛍️ Products page with search functionality
- ➕ Add new products via form
- ✏️ Edit product prices
- 🗑️ Delete products
- 📱 Responsive design

## Setup Instructions

### Install dependencies
npm install

### Run the backend
npm run server

### Run the frontend
npm run dev

### Run tests
npm test

## Tech Stack
- React
- React Router DOM
- JSON Server
- Vitest
- React Testing Library
